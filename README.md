# Adopt a Canine

## Description

Adopt a Canine is a 3 week Calpoly SLO student driven take on a real non-profits website powered by NextJS and React. Here, visitors can view canines available for adoption, learn about the non-profits mission, and make donations through paypal. Clicking on a canine will take you to a dedicated page with all the information an adopter may need. A contact page is also included along with where the non-profit is currently located.

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Tech Stack

Next.js, React, Typescript, MongoDB, Vitest

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
